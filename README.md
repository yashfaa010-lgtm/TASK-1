# WD_1_ResponsiveLandingPage_byte

Responsive landing page for **Mizu**, a fictional self-watering planter. Built for Task 1 of the Arithmatrix AVIP 2026 Web Development track.

**Live demo:** coruscating-sprinkles-24bda0.netlify.app

## Features
- Hero section, three product features, and a pre-order call-to-action
- Responsive at desktop, tablet (about 820px) and mobile widths
- Dark "bioluminescent" design with glowing firefly particles that flee the cursor
- Interactive plant demo: a moisture slider droops and recolours the plant, and water drops fall when it is thirsty
- 3D tilt on the demo card, cursor spotlight on feature cards, scroll-triggered counters and a scrolling marquee
- Hover effects on buttons and feature cards; respects `prefers-reduced-motion`
- Semantic HTML (`header`, `nav`, `main`, `section`, `article`, `footer`), title and meta description

## Run it
Open `index.html` in a browser. No build step.
